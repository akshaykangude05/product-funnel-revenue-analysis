# 📊 Product Funnel Performance & Revenue Leakage Analysis

## 🔍 Overview
This project analyzes user behavior across an e-commerce purchase funnel to identify where users drop off and how those drop-offs translate into potential revenue loss.

Using SQL (PostgreSQL) for data modeling and Power BI for visualization, the project focuses on business-driven insights rather than just dashboards.

---

## 🎯 Business Problem
E-commerce teams often struggle to answer:
- Where exactly are users dropping off in the funnel?
- Which funnel stage contributes most to revenue loss?
- Should optimization focus on checkout or earlier engagement?

This project addresses these questions using funnel analysis and revenue impact estimation.

---

## 🧠 Key Insights
- Only ~25% of user sessions reach the purchase stage.
- The highest user drop-off occurs between Page View → Product View, indicating weak early-stage engagement.
- Despite a 100% observed purchase conversion rate, an estimated ₹5.5K in potential revenue is lost due to early funnel exits.
- Improving product discovery would have a higher business impact than optimizing checkout.

---

## 📈 Metrics Tracked
- Total Sessions
- Purchase Conversion % (Observed)
- Average Order Value (AOV)
- Actual Revenue
- Estimated Revenue Leakage (Simulated)

> ⚠️ Note: Expected revenue and revenue leakage are simulated estimates based on assumptions.  
> The purpose is to demonstrate analytical methodology, not production revenue forecasting.
